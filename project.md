Çekirdek modüller (12 büyük parça) 1. CLI / TUI Layer Ne yapar: Kullanıcı ile etkileşim, terminal UI, slash command'lar, paneller. Tech: Ink (React for terminal) — en olgun TS çözümü veya Clack/Prompts (daha hafif, basit) İçerik: Ana ekran (chat panel + status bar + tools panel) Slash command parser (/scan, /agent michael, /help) Multi-pane layout (chat | output | sidebar) Markdown render (mesajlar) Spinner, progress bar, table render Theme system (Çiko/Pacino dark theme default) Çıkartılması: ~1500-2500 satır TS 2. Provider Abstraction Layer Ne yapar: Anthropic, OpenAI, GLM, DeepSeek, Bedrock vs farklı API'leri tek arayüze çevirir. Tech: Native fetch + her provider için adapter sınıfı Yapılacaklar: Stream parser (SSE — her provider'ın formatı farklı) Tool calling format converter (Anthropic XML, OpenAI function-call, Gemini tools — hepsi farklı) Token counter (her provider farklı tokenizer) Rate limit + retry logic Error normalization Model registry (model adı → provider eşleme) Catch: Anthropic prompt caching, OpenAI strict mode, Gemini cached content gibi her provider'ın özel feature'ları var. Hepsini desteklemek yarı yıl, sadece 2-3 provider iyi destek 1-2 hafta. Çıkartılması: ~3000-5000 satır TS 3. Tool Execution Engine Ne yapar: LLM "şu tool'u çağır" dediğinde sandbox içinde çalıştırır, sonucu LLM'e geri verir. Yapılacaklar: Tool registry (built-in tools: bash, read, write, edit, search) Custom tool loader (plugin tool'larını yükle) Permission system (auto-approve / ask / deny) Sandbox (process isolation, timeout, max output) Streaming output (uzun komutlarda canlı render) Tool result formatter (LLM'in anlayacağı formata) Catch: Permission UX zor — Claude Code'un asıl başarısı bu. Yanlış tasarlasan ya çok soruyor (annoying) ya az soruyor (tehlikeli). Çıkartılması: ~2000-3000 satır TS 4. MCP Client Ne yapar: Model Context Protocol sunucularına bağlanır (HexStrike gibi), tool listesi alır, çağırır. Tech: @modelcontextprotocol/sdk (Anthropic'in resmi SDK'sı, MIT) Yapılacaklar: stdio transport (local process) SSE transport (HTTP streaming) WebSocket transport (yeni) Tool discovery Resource discovery Prompt template discovery Connection pool + reconnect Multi-server merge (10 MCP server'ı tek tool listesine birleştir) Catch: MCP spec hâlâ yeni, sürekli değişiyor. Anthropic SDK'yı kullanmak yerine kendin yazarsan her ay updates sürekli iş. Çıkartılması: ~1500 satır TS (SDK kullanırsan), ~5000 satır (sıfırdan) 5. Session / State Management Ne yapar: Conversation history'yi tutar, persist eder, resume yapar. Yapılacaklar: Mesaj store (SQLite veya JSON) Session metadata (id, başlık, model, oluşturulma) Context window management (token sayar, eski mesajları compact'lar) Summarization on overflow (LLM ile özetle, kısalt) Export/import (JSON, markdown) Multi-session UI (tab gibi geç) Çıkartılması: ~2000 satır TS 6. Agent System Ne yapar: Michael/Tony/Carlito gibi farklı persona'ları yönetir. Yapılacaklar: Agent persona definition (markdown frontmatter veya YAML) Per-agent: model seçimi, temperature, allowed tools, system prompt Agent switcher (UI + CLI) Inter-agent handoff — bir agent başka agent'ı çağırır Inter-agent context passing — Michael'ın çıktısı Tony'ye giriş olur Orchestration layer (sıralı / paralel / koşullu) Catch: Multi-agent orchestration gerçek araştırma alanı. Naive impl yapsan çalışır ama "Michael'ın output'unu Tony nasıl yorumlasın" gibi konularda iterate ettiğin çok şey çıkacak. Çıkartılması: ~2000-3000 satır TS 7. Plugin / Extension System Ne yapar: Kullanıcılar yeni tool/agent ekleyebilsin. Yapılacaklar: Plugin loader (~/.config/aipacino/plugins/) Plugin API (tool registration, event hooks, config modification) npm package support (bun install) Hot reload (dev mode) Plugin marketplace (ileride) Çıkartılması: ~1500 satır TS 8. Auth / API Key Yönetimi Yapılacaklar: Multi-provider key storage (encrypted with macOS Keychain / linux libsecret) OAuth flow (Z.AI Coding Plan, GitHub Copilot vs) Proxy support (kurumsal müşteri) Subscription validation (kendi paid tier'ın için) Çıkartılması: ~1000 satır TS 9. Config System Yapılacaklar: ~/.config/aipacino/config.json (global) .aipacino/config.json (proje bazlı) Env var override Schema validation (Zod) Migration on version upgrade Çıkartılması: ~500 satır TS 10. Logging / Telemetry Yapılacaklar: Structured logging (debug/info/warn/error) Local log file rotation Opt-in telemetry (kullanıcı izin verirse anonim usage) Crash reporting (Sentry?) Çıkartılması: ~500 satır TS 11. Update / Distribution Yapılacaklar: Auto-update mechanism (Tauri update server veya custom) Single binary build (bun build --compile) npm publish pipeline Homebrew formula (Mac) Linux packages (deb/rpm) Windows installer (zaten Bun tek dosya verir) Çıkartılması: Code az ama config + CI/CD çok 12. Hidden costs (kimse söylemez) 1. Streaming + tool calling state machine bug'ları LLM streaming'de tool çağırınca, partial JSON gelir, parse etmen lazım, edge case'ler bitmez. Claude Code 2 yıldır iterate ediyor hâlâ bug fix. 2. Provider'ların API breaking changes Anthropic 6 ayda 1, OpenAI 3 ayda 1 breaking change atar. Sen geride kalmaya başlarsın. OpenCode + community bunu absorbe ediyor, sen tek başına kalırsın. 3. Token counting Her provider farklı tokenizer. Yanlış sayım = context overflow = session crash. 4. Permission UX "Bu komutu çalıştırayım mı?" diye kaç kere sorulur, hangi pattern'lerde otomatik onay? Bunu yanlış yaparsan ya kullanıcı boğulur ya tehlikeli komutlar geçer. Claude Code'un asıl gizli sosu bu, herkes diğer şeyleri taklit eder ama bunu beceremezler. 5. Multi-platform binary Mac (Intel + ARM), Linux (x86 + ARM), Windows. Bun yardımcı ama her platformda farklı bug'lar. 6. MCP ecosystem fragmentation MCP server'lar farklı versiyonlar kullanır, transport farklılıkları (stdio vs SSE vs streamable HTTP), spec değişiklikleri. Bu uyumluluk senin işin. 7. Documentation Sıfırdan ürün = sıfırdan dokümantasyon. Her feature için açıklama, example, troubleshooting.
